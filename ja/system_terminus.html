システムの概念

この概念には数十もの定義がある。それらを分析すると、システムという概念の定義が、形式だけでなく内容においても変化してきたことがわかる。システム理論が発展し、この概念が実践に用いられるようになるにつれてシステムの定義に生じた、主要な変化を見ていこう。

要素と関係

最も初期の定義は、なんらかの形で、システムが要素（部分、構成要素）aᵢ と、それらのあいだの結合（関係）rⱼ からなると述べていた。

$$S = \{a_i,\; r_j\}$$

$$S = \langle A,\; R \rangle$$

$$S = A \cap R$$

これらの形式化された記法では、異なる集合論的な表現が用いられている。最初の二つでは、要素の集合と関係の集合のあいだの相互関係を考慮せずに集合が指定されている。三つ目は、システムが何らかの要素と結合の単なる寄せ集めではなく、共通部分に入る要素と結合だけを含むという事実を反映している。

ルートヴィヒ・フォン・ベルタランフィは、システムを「相互作用する構成要素の複合体」、あるいは「互いに、また環境に対して一定の関係にある要素の集合」と定義した。『ソビエト大百科事典』では、システムはギリシャ語の systema、すなわち「組み立て」——部分から組み立てられ、結び合わされたもの——の直訳によって定義されている。

「要素」と「構成要素」、「結合」と「関係」という語は、通常は同義語として用いられる（とりわけ定義の翻訳においてはそうである）。しかし厳密に言えば、「構成要素」は「要素」よりも一般的な概念であり、要素の集まりを指しうる。「結合」と「関係」という概念についても、さまざまな見方が存在する。

要素が根本的に異質であることがわかっている場合には、要素の異なる集合を区別することによって、定義においてただちにそれを考慮に入れることができる。

$$S = \langle A,\; B,\; R \rangle$$

М・メサロヴィッチの定義では、入力対象（システムに作用するもの）の集合 X と、出力結果の集合 Y が区別され、それらのあいだに一般化された交わりの関係が立てられる。これは著者本来の記法でも、ほかの交わりの記号を用いても表しうる。

$$S \subseteq X \times Y$$

ある種の関係が異なる集合の要素のあいだにのみ当てはまり、それぞれの集合の内部では用いられない場合、それは次のように反映できる。

$$S = \{a_i \; r_j \; b_k\}$$

  • $\{a_i \; r_j,\; b_k\}$ — 元の集合 $A$ と $B$ の要素から形成される、新しいシステムの要素。

この形式の記法は、数理言語学では統辞体（シンタグマ）と呼ばれる。

要素と関係の性質

要素と関係を精密化するために、定義には性質が組み込まれる。たとえば A・ホールの定義では、性質（属性）Q_A が要素（対象）の概念を補っている。

$$S = \langle A,\; R,\; Q_A \rangle$$

  • $Q_A$ — 性質（属性）

А・И・ウエモフは、「もの」「性質」「関係」という概念によってシステムを定義し、二重の定義を提案した。一方では性質が要素（もの）を特徴づけ、他方では性質が結合（関係）を特徴づける。

$$S = \langle a_i,\; r_j,\; q_i \rangle \quad \text{and} \quad S = \langle a_i,\; r_j,\; q_j \rangle$$

  • $a_i$ — 要素
  • $r_j$ — 結合（関係）
  • $q_i$ — 要素の性質
  • $q_j$ — 結合（関係）の性質

目標

その後、システムの定義に目標という概念が現れた。最初は暗黙のうちにであった。Ф・Е・テムニコフの定義では「システムとは組織化された集合である」とされ（「組織化された」という概念を解きほぐすと目標が現れる）、哲学辞典ではシステムは「互いに関係と結合のうちにあり、一定の全体的な統一をなす要素の集合」とされている。次いで目標は、最終結果、システム形成の基準、あるいは機能という形で現れ（В・И・ヴェルナツキー、Р・ギブソン、П・К・アノーヒン、М・Г・ガーゼ＝ラポポルトの定義を参照）、さらにのちには目標が明示的に言及されるようになった。

記号によって、この群の定義は次のように表せる。

$$S = \langle A,\; R,\; Z \rangle$$

  • $Z$ — 目標、目標の集合あるいは構造。

定義のなかには、目標形成の条件——環境、時間区間、すなわちシステムとその目標が存在する期間——を指定するものもある。たとえば В・Н・サガトフスキーの定義がそうであり、これは目標の構造化の技法の一つの基礎にもなっている。システムとは「定められた時間区間において、特定の目標にしたがって環境から区別された、機能的な要素とそれらのあいだの関係の有限集合」である。

$$S = \langle A,\; R,\; Z,\; S_R,\; T \rangle$$

  • $S_R$ — 環境
  • $T$ — システムの存在時間

観察者

さらに進んで、システムの定義には、要素、関係、目標とともに観察者 N ——すなわち、研究あるいは意思決定の過程で対象やプロセスをシステムとして表現する人——が含まれるようになった。

$$S = \langle A,\; R,\; Z,\; N \rangle$$

  • $N$ — 観察者、研究者

W・R・アシュビーは、研究されるシステムと研究者との相互作用を考慮に入れる必要を指摘した。しかし観察者を明示的に含めた最初の定義を与えたのは Ю・И・チェルニャークである。「システムとは、研究と認識の課題において、対象の性質とそれらの関係が主体（研究者、観察者）の意識に反映されたものである」。

$$S = \langle A,\; R,\; Z,\; N \rangle$$

この定義のその後の版において、Ю・И・チェルニャークは観察者の言語も考慮に入れ、次の定式から出発した。「システムとは、研究と認識の課題において、対象、関係、およびそれらの性質を、観察者（研究者、設計者）の言語で表現したものである」。

$$S = \langle A,\; R,\; Z,\; N,\; L_N \rangle$$

  • $L_N$ — 観察者の言語

システムの定義は、さらに多くの構成要素を含みうる。これは、具体的な条件のもとで要素や関係などの種類を区別する必要があることによる。

システムの定義の発展

システムの定義の発展（要素と関係、次いで目標、次いで観察者）を、認識論的カテゴリーの用いられ方の発展と比べると、類似が見てとれる。初期にはモデル（とりわけ形式的なもの）は、要素と結合、それらのあいだの相互作用だけを考慮に入れることにもとづいていた。次いで目標と、その形式化された表現の方法（目的関数、有効性の基準など）の探索へ関心が移った。そして一九六〇年代以降は、観察者——モデリングを行い、あるいは実験を遂行する人（物理学においてさえ）、すなわち意思決定者——にますます大きな注意が払われるようになった。

このことを踏まえ、システムという概念の本質のより深い分析にもとづくならば、この概念を認識論の、反映の理論のカテゴリーとして扱うのが適切だと思われる。

システムの作業定義

システムのさまざまな定義とその発展を考えるとき、そのいずれか一つを主要な定義として選び出すことなく言えるのは、「システム」のような（通常は直観的に把握される）概念を簡潔に定義することがいかに難しいかということだけではない。対象をシステムとして表現するさまざまな段階において、またさまざまな具体的な状況において、異なる定義が用いられうるという事実もまた認めなければならない。さらに、システムについての理解が精密化され、あるいはその研究の別の層へ移るにつれて、システムの定義は精密化されうるだけでなく、精密化されるべきである。

要素、関係、目標、観察者を——ときにはシステムを表現するための観察者の「言語」をも——含む定義は、問題を定式化し、システム分析の方法論の主要な段階を描き出すのに役立つ。たとえば組織システムでは、決定を下す権限をもつ人が特定されていなければ、システムが創設された目標は達成されないかもしれない。しかし観察者が自明であるシステムも存在する。目標という概念を明示的に用いる必要さえない場合もある。

たとえば Ю・А・ウルマンツェフが、植物のような比較的低次の生物学的対象を研究するために練り上げたシステム理論の版には、目標という概念が含まれていない。この対象群には目標が特徴的でないからである。その代わり、合目的性と発展という考えは、特別な種類の関係——組成の法則——という形で表現されている。

したがってシステム分析を行うにあたっては、まず可能なかぎり完全なシステムの定義を用いて状況を表現し、次いで意思決定に影響を与える最も本質的な構成要素を特定したうえで、分析の進行に応じて精密化し、拡張し、あるいは狭めうる「作業」定義を定式化すべきである。

システムの「作業」定義は、研究者（開発者）がその記述に取りかかるのを助ける。採用された「作業」定義に含まれる必要な要素、関係、それらの性質、その他の構成要素を正しく選び出すためには、システムのこの最初の言語的な表現を定式化する人々が、これらの概念を同じ意味で用いていなければならない。

システムの定義の選択は、採用された概念的な枠組みを反映しており、本質的にはモデリングの始まりである。したがって最初から定義を記号的な形で提示することが望ましく、それによってシステムの開発あるいは研究に加わるすべての者が、より一義的に理解できるようになる。

システムの定義をその研究を始める手段とみなし、システムを変換あるいは設計する際に全体性を保とうとする志向から、本節の著者は次のような定義を提案するに至った。そこではシステムは（すでに引用した定義でなされているように）最も基本的な粒子へ分解されるのではなく、研究されるあるいは創設されるシステムの存在と機能にとって根本的に必要な、高次の構成要素の集まりとして表現される。

$$S = \langle Z,\; \text{Str},\; \text{Tech},\; \text{Cond} \rangle$$

  • $\{Z\}$ — 目標の集合あるいは構造
  • $\{\text{Str}\}$ — 目標を実現する構造（生産的、組織的なものなど）の集合
  • $\{\text{Tech}\}$ — システムを実現する技術（方法、道具、アルゴリズムなど）の集合
  • $\{\text{Cond}\}$ — システムの存在条件、すなわちその創設、機能、発展に影響を与える要因

この定義によって、研究対象のシステムを壊すことなく、その主要な構造をそのうちに保ち、掲げられた目標にしたがってそれらを発展させることが可能になる。新しいシステムを創設する際には、全体的な設計構想を得て、システムの創設への目標志向的なアプローチを実現するのに役立つ。

システムの物質性と非物質性

一九六〇年代から七〇年代にかけてのシステム研究の形成期には、システムが物質的なものか非物質的なものかをめぐる論争がしばしば起こった。この問題は今日でも、すべての人にとって明快なわけではない。

一方では、システムの物質性を強調しようとして、定義のなかの「要素」という語を「もの」「対象」「品物」といった語に置き換えた研究者もいた。後者もまた抽象的な対象や研究の主題として解釈されうるのだが、これらの定義の著者たちが、システムの手に触れうる性質と物質性に注意を向けさせようとしたことは明らかである。

他方、先に引用した Ю・И・チェルニャークの定義、とりわけ С・オプトナーの定義では、システムは表象としてしか——すなわち研究者や設計者の意識のうちにのみ存在するものとしてしか——解釈しえない。反映の理論の法則性を理解している専門家であれば、こう反論するだろう。構想（システムの理念的な表象）はのちに物質的な体現において存在することになるのであり、意思決定の問題にとっては、システムという概念が問題を研究し課題を解く手段として役立ちうることを強調するのが重要なのだ、と。それにもかかわらず、当時これらの定義は、システムの物質性を主張する人々、とりわけ哲学者から批判を受けた。

В・Г・アファナーシエフは、システムの物質性あるいは非物質性をめぐる論争が不毛であることを示した。「……客観的に存在するシステム——そしてシステムの概念。システムを認識する道具として用いられるシステムの概念——そして再び現実のシステム、その知識は我々のシステム的な表象によって豊かにされている。これがシステムにおける客観的なものと主観的なものの弁証法である……」。

論じている問題との関連で指摘しておきたいのは、『ソビエト大百科事典』には、先に引用した定義とともに次のものも挙げられていることである。システムとは「法則によって互いに結ばれた、自然と社会にかかわる実在、現象、知識の客観的な統一」である。すなわち、要素（したがってシステム）という概念が、現に存在し物質的に実現された対象にも、それらの対象やその将来の実現についての知識にも適用されうることが強調されている。

このようにシステムという概念においては（認識のほかのいかなるカテゴリーにおいてもそうであるように）、客観的なものと主観的なものが弁証法的な統一をなしている。したがって語るべきはシステムの物質性や非物質性ではなく、研究対象にシステムとして接近すること、認識あるいは創設のさまざまな段階でそれらを異なる仕方で表現することである。

システムを考察する層

たとえば Ю・И・チェルニャークは、同一の対象がその考察の異なる段階においてさまざまな側面から表現されうることを示し、それに応じて同一のシステムを異なる存在の水準——哲学的（認識論的）、科学研究的、設計的、工学的、といった具合に、物質的な体現に至るまで——において描くことを提案している。

言い換えれば、システムを考察する異なる段階においては、「システム」という語に異なる概念を込めることができる。いわばシステムが異なる形態で存在することを語りうるのである。М・メサロヴィッチは、システムを考察する層を区別することを提案している。

同様の層は、対象の創設の過程だけでなく、その認識の過程にも存在しうる。すなわち、現に存在する対象を、意識のうちに（あるいはモデルのうちに）抽象的に構想されたシステムとして表現する過程である。それはのちに新しい対象を創り出し、既存の対象の変換（再編、再構築）のための勧告を練り上げるのに役立ちうる。

システム分析の方法論（あるいはシステム研究のモデル）は、必ずしもシステムの認識あるいは設計の全過程を包含する必要はなく、そのいずれかの層のために練り上げられてもよい（実務では通常そうである）。システムの研究者あるいは開発者のあいだで用語上その他の食い違いが生じるのを防ぐには、まずシステム考察のどの層について論じているのかを明確に指定しなければならない。
