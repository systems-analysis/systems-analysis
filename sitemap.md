# Sitemap

> Global semantic router of Systems-Analysis.ru. This root sitemap routes to language-specific sitemap files and deep branch sitemap files. It does not rank languages by priority. It describes the project through language-specific access paths and branch-specific knowledge structures. Any HTML content page on this domain — the static public site and all wiki branches — can be retrieved as Markdown by sending the request header `Accept: text/markdown`; appending `.md` to content-page URLs is not supported.

## Root AI routing file

- [https://systems-analysis.ru/llms.txt](https://systems-analysis.ru/llms.txt) — Root llms.txt file: detailed routing layer for language models and AI agents, covering languages, content layers, and subject branches.
