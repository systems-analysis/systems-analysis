Mga Regularidad ng mga Sistema

Ang regularidad ay nauunawaan bilang isang matatag na ugnayan sa pagitan ng mga bagay, pangyayari, o proseso na pinag-aaralan. Ang isang regularidad ay tinatawag na pangkalahatang sistemiko kung ito ay taglay ng mga sistema ng iba’t ibang likas at iba’t ibang layunin.

Ang mga regularidad ng paggana at pag-unlad ng mga sistema (mga regularidad ng mga sistema) ay mga pangkalahatang sistemikong regularidad na naglalarawan sa mga pundamental na katangian ng pagbuo, paggana, at pag-unlad ng mga kumplikadong sistema.

1. Mga regularidad ng kabuuan at additivity

  • Kabuuan, o emergence
  • Progresibong sistematisasyon
  • Progresibong faktorisasyon
  • Additivity

2. Mga regularidad ng pagbuo ng layunin

  • Ang pagsalalay ng pag-unawa at pagbabalangkas ng isang layunin sa yugto ng pagkilala sa bagay (proseso) at sa oras.
  • Ang pagsalalay ng layunin sa mga panlabas at panloob na salik.
  • Ang posibilidad at pangangailangan ng pagbabawas ng gawain ng pagbabalangkas ng isang pangkalahatang (buo, global) layunin tungo sa gawain ng pagbubuo ng istruktura nito.
  • Mga regularidad ng pagbuo ng mga istruktura ng layunin.

3. Mga regularidad ng hierarkikal na pagkakaayos

  • Hierarkiya
  • Komunikatibiti

4. Mga regularidad ng katuparan ng sistema

  • Equifinality
  • Batas ni Ashby ng kinakailangang pagkakaiba-iba
  • Prinsipyo ni Fleishman ng potensyal na katuparan

5. Mga regularidad ng pag-unlad ng sistema

  • Sariling pag-oorganisa
  • Historisidad
