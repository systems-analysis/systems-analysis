Metodolohiya ng Pagsusuri ng mga Sistema ni Quade

Karaniwang sinusundan ng pagsusuri ng mga sistema ang sumusunod na pagkakasunud-sunod:

  1. Pagbabalangkas ng suliranin;
  2. Pagpili ng mga alternatibong lapit sa paglutas ng suliranin;
  3. Pagsisiyasat sa mga mapagkukunang gagastusin sa paglutas ng suliranin;
  4. Paggawa ng modelo;
  5. Pagpili ng mga pamantayan sa pagtataya;
  6. Paghahambing ng mga alternatibo at pagpapasya.

Ang pagbabalangkas ng suliranin ang pinakamahalagang elemento ng pagsusuri ng mga sistema at kinabibilangan ng pagsasaad ng kakanyahan ng suliranin, pagtukoy ng saklaw ng pag-aaral, pagtatatag ng mga panimulang datos, at pagkilala sa mga layunin.

Ang pagpili ng mga alternatibong lapit sa paglutas ng mga suliranin ay binubuo ng paglilista ng mga alternatibong iyon (mga paraan) na, batay sa paunang pagsasaalang-alang, ay maaaring gamitin upang lutasin ang binalangkas na suliranin. Sa kurso ng pag-aaral, ang ilang alternatibo ay tinatanggal at ang mga bago ay ipinakikilala.

Ang pagsisiyasat sa mga mapagkukunang gagastusin sa paglutas ng suliranin ay isang pangunahing yugto ng ekonomikong pagsusuri, kung saan tinutukoy ang mga kinakailangang materyal at pinansyal. Karaniwan, ang mga sistema ng armas ay pinipili batay sa pinakamababang gastos para sa isang partikular na antas ng bisa.

Ang paggawa ng modelo ay isang yugto ng pag-aaral kung saan ang isang analogo ng tunay na proseso ay binubuo sa pamamagitan ng pagpapakita ng mga pinakamahalagang salik gamit ang matematikal na mga relasyon (analitikal na mga modelo), sa pamamagitan ng kompyuter (mga modelong kompyuter), o sa pamamagitan ng isang espesyal na “laro” (mga modelong pang-laro).

Ang pagmomodelo sa pagsusuri ng mga sistema ay lalo pang mananaig, lalo na kaugnay ng pag-unlad ng mga pamamaraan ng matematikal na pagmomodelo at mga kompyuter.

Ang pagpili ng mga pamantayan sa pagtataya ay isang lubhang kritikal na yugto ng pagsusuri ng mga sistema at binubuo ng pagtukoy ng isang dami (o isang sistema ng mga dami) na ang numerikal na halaga ay maaaring gamitin upang husgahan ang tagumpay ng solusyon. Para sa kasiya-siyang pagpapatakbo ng mga pamamaraan ng pagsusuri ng mga sistema, itinuturing na mahalaga na ang mga pamantayang inaadopt sa bawat antas ng pamamahala ay maiugnay sa iisang lohikal na sistema. Ang pinakamahalagang pamantayan sa pinakamataas na antas (pamunuan ng ministeryo ng depensa) ay ang ratio ng kahusayan-sa-gastos ng sistema.

Ang paghahambing ng mga alternatibo at pagpapasya ay ang huling yugto ng pagsusuri, kung saan ang mga paraan ng paglutas ng binalangkas na suliranin ay sinusuri laban sa napiling pamantayan. Bukod sa dami-tayang pagsusuri ng iba’t ibang alternatibo, maaari ring iharap ang mga lohikal na paghatol na nagpapahiwatig ng kahigitan ng isang alternatibo kaysa sa iba.
